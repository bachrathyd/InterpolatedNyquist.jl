Float32 WebGPU port of the :unwrap argument-principle march of InterpolatedNyquist.jl / NyquistGPU. One GPU thread per chart point. Starting WebGPU...

Advanced: order n and march settings
Leave n empty: it is computed automatically (shown above the Advanced section). Settings are expressions of the parameters (an axis parameter stands for max |value| over its range) with pi, inf, min, max, abs, e.g. hmax = pi/(2*τ). Neutral systems (the highest power of λ also multiplies a delay term): the phase ripple never decays and the default ωmax = 1e5 fails; use a small ωmax such as 200–500 with hmax = pi/(2*τ) on the whole line.

  Each point marches λ = iω, ω ∈ [10⁻⁹, ωmax], unwrapping arg D with one evaluation of D and dD/dω (complex dual numbers) per step and
  step control from the trapezoid phase prediction; Z = n/2 − Δarg D/π counts the roots with Re λ > 0, and the deepest |D| minima
  give first-order estimates of the roots near the axis (σ = the rightmost; with "exact root" the tracked minima are polished by
  Newton steps in the complex plane). Large charts run as several row bands so no single GPU submission is long.
  The examples are the case studies of the paper's appendix (A.1–A.12) that run in real time; each is plain text in the equation box,
  compiled to WGSL like a typed equation.

How to use this page

    
What it is

    
Real-time stability charts of linear time-delay systems, computed on your own GPU with WebGPU: every chart point counts the roots of the characteristic function D(λ) in the right half-plane (Z) by the argument principle and estimates the rightmost root σ. Needs Chrome or Edge 113+ (desktop); nothing is sent to a server.

    
Equation

    
    
      
  • Type D(λ) as one expression in λ (or lambda; the λ button inserts it): + - * / ^, exp log sqrt sin cos tan sinh cosh tanh exprel pow, pi, i. Write 2*λ, not 2λ.
    • 
      
  • name = expr defines a helper, name = 3 a fixed constant; the last line is D; # starts a comment.
    • 
      
  • Every other name is a parameter. Range lines: P = 0:2, P = 0:0.01:2 (step = grid along an axis), P = 0:2 @ 0.5 (default value).
    • 
      
  • Distributed delays: integral(f, θ, a, b), exact for polynomial × exponential kernels.
    • 
      
  • Matrix models: expand the determinant into a scalar expression (no determinants or loops).
    • 
      
  • Neutral systems (the highest power of λ also multiplies a delay term): use a moderate ωmax (200–500) and a step cap such as hmax = pi/(2*τ) (Advanced).
    • 
    

    
Parameters and axes

    
    
      
  • Each parameter: value, min, slider, max. The X / Y buttons choose the chart axes (their min / max are the chart range); Z adds a third axis: the 3D view (also the "3D view" button of some examples).
    • 
      
  • Sliders recompute live; editing min / max rewrites the range line in the text.
    • 
    

    
Navigation

    
    
      
  • 2D: wheel zooms at the cursor, middle-drag pans, left-drag zooms to a box, double-click resets. Touch: pinch to zoom, two fingers to pan.
    • 
      
  • 3D: drag rotates, wheel zooms, double-click resets the view; the α sliders set the interior and boundary opacity.
    • 
      
  • The divider between the panels can be dragged (double-click resets it).
    • 
    

    
Modes and settings

    
    
      
  • σ: exact root (Newton-polished, default) or fast (first-order estimate).
    • 
      
  • Resolution Auto (20 fps) sizes the grid to about 50 ms per chart; fixed sizes up to 4K use the time limit (1–600 s, default 5 s) after which a chart is stopped.
    • 
      
  • ωmax: end of the march along λ = iω; tolerance: phase error allowed per step (smaller = safer, slower). The order n is computed automatically.
    • 
    

    
Output

    
    
      
  • Save PNG: the chart at full resolution. Save STL (3D): the stability boundary as a closed surface. Copy link: a URL with the equation, parameters, view and settings.
    • 
    

    
Colours

    
    
      
  • Stable (Z = 0): viridis by σ of the rightmost root, from the σ colour floor (dark) to 0 (bright yellow). Unstable: reds by the number of unstable roots Z = 1 … 6+. White: stability boundary. Grey: the march failed.
    • 
    

    
Validation

    
Anonymous visit statistics are collected with GoatCounter: page views, which examples are opened, and which features are used (3D, zoom, export, ...); own equations are counted only as "an own equation was used". No cookies, no personal data, no equation text, no parameter values.

    
The counts match the Julia engine of InterpolatedNyquist.jl on 28 reference charts (run the check). Source and paper: github.com/bachrathyd/InterpolatedNyquist.jl.
