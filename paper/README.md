# Paper build

All numbers, tables and figures in the manuscript are generated by the scripts
in `scripts/` and written to `data/` (CSV), `tables/` (booktabs fragments),
`figures/` (PDF/PNG) and `generated/` (TeX macros with machine specs).

## One-time setup

```powershell
# from the repository root
julia --project=paper/scripts -e "using Pkg; Pkg.develop(path=pwd()); Pkg.instantiate()"
```

## Regenerate all data / figures / tables

```powershell
julia --project=paper/scripts -t auto paper/scripts/generate_all.jl
# options: --force (ignore caches)  --fast (draft grids, skip solver zoo)
#          --only=s01_showcase,s03_convergence
```

Full regeneration takes roughly 1-2 h (dominated by the solver zoo and the
gallery); `--fast` finishes in a few minutes.

For honest cold-start timings the driver's `s06` study launches
`scripts/ttfx_probe.jl` in fresh Julia processes; these rows end up in
`data/ttfx.csv`.

## Build the PDF

```powershell
cd paper
powershell -File build.ps1     # pdflatex -> bibtex -> pdflatex x2 (MiKTeX)
```

The manuscript compiles even when figures/tables are missing (placeholder
boxes are shown, see `\maybefig` in `macros.tex`).

Benchmark tips: run on AC power with the High-Performance power plan, close
background applications. The timings quoted in the submitted manuscript are
frozen in the committed CSV files under `data/` (machine specs in
`data/machine.txt` and `generated/machine.tex`).
